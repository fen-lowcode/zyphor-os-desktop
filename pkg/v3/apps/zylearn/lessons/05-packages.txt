# Package management with apt

Zyphor OS is Debian-based, so software is installed with apt - a trusted
catalogue, instead of downloading random installers.

Try it:
  apt search tree | head      search for a package
  apt show tree               read what a package does
  sudo apt update             refresh the list of available software
  sudo apt install tree       install it
  sudo apt remove tree        uninstall it (your files stay)

Good habits:
  - Run "sudo apt update" before installing.
  - Read what apt is about to do before you press Y.
  - Only use sudo when you understand why the command needs it.
